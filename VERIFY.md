# Verification Guide

The JSON files in this repository contain raw output from the LJX Discovery Engine. To prove that these files have not been altered, tampered with, or edited since the engine generated them, we provide a cryptographic manifest (`SHA256SUMS`).

### How to verify the proofs yourself:

If you are on Linux, macOS, or using Termux, open your terminal, navigate to this folder, and run:

```bash
sha256sum -c SHA256SUMS
```

If every line prints `OK`, you have cryptographically verified that these results are exactly as they were generated by the LJX Core pipeline.

### What this proves:
1. **Provenance:** These results were generated by our engine.
2. **Immutability:** The data has not been manually adjusted or cherry-picked after the fact.

For details on the mathematical honesty of the pipeline (including failures), see the `5_Honest_Failures` folder.
